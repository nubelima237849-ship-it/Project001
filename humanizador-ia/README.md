# humanizador-ia

App Vite + React para humanizar texto. Aún es la plantilla base; la lógica de humanización está pendiente.

## Ejecutar en tu PC

Requiere Node `^20.19.0 || >=22.12.0`.

```bash
npm install
npm run dev
```

Abre la URL que muestra la terminal (normalmente http://localhost:5173).

## Otros comandos

- `npm run lint` — Oxlint.
- `npm run build` — build de producción en `dist/`.
